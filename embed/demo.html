Embed an India Macro chart

One <div>, one <script>, no key and no build step. The numbers come from RBI's own publications; the chart re-reads them from the static API each time the page loads, so it is never staler than the last daily refresh.

One indicator

<div data-imwr-series="repo" data-imwr-range="10y" data-imwr-height="200" data-imwr-frame="on"></div>
<script src="https://mayankmohan1992.github.io/india-macro-war-room/embed.js" async></script>

CPI's official y-o-y series only starts at the 2024=100 base-year revision, so that chart is genuinely short — the dashboard draws the longer index-derived history, and says so. No series is padded to look longer than it is.

Several, on any page

<!-- the script tag goes once, at the end; every div with data-imwr-series renders itself -->
<div data-imwr-series="usdinr"  data-imwr-height="150"></div>
<div data-imwr-series="gsec"    data-imwr-height="150"></div>
<div data-imwr-series="liquidity" data-imwr-height="150"></div>

Match your page

The chart inherits your light/dark preference and can be recoloured per element. Any indicator id from api/v1/index.json works.

<div data-imwr-series="credit" data-imwr-range="3y" data-imwr-title="Bank credit growth"
     style="--imwr-accent:#2f6f4f; --imwr-rule:#cfd8d2; --imwr-ink:#14231b"></div>

Notes

The API is static files on GitHub Pages with access-control-allow-origin: * — no key, no quota, no rate limit, and nothing to sign up for. If RBI is down, the data just stays at yesterday's refresh; the chart reads the last published copy.

The credit line under each chart is part of the MIT licence's attribution: it is not optional. The data is RBI's, the arithmetic and the caveats are documented in the repository.
